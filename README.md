## 1. Descricao do problema

Em uma escola, organizar as notas dos alunos pode facilitar
a analise do desempenho escolar. Este projeto utiliza a
programacao em C para ordenar as notas de 10 alunos,
da maior para a menor.

## 2. Objetivo

Desenvolver uma aplicacao em linguagem C que utilize
o algoritmo Bubble Sort para organizar notas escolares
em ordem decrescente.

## 3. Funcionamento do Bubble Sort

O Bubble Sort compara elementos adjacentes de um array.
Neste projeto, quando uma nota e menor que a nota seguinte,
as duas notas trocam de posicao.

Esse processo se repete ate que as notas estejam
organizadas da maior para a menor.

## 5. Como compilar e executar

Salve o codigo no arquivo notas_escolares.c.

Para compilar, utilize:

gcc notas_escolares.c -o notas_escolares

Para executar no Linux:

./notas_escolares

No Windows, execute:

notas_escolares.exe

## 6. Exemplo de entrada e saida

O programa utiliza inicialmente as seguintes notas:

7.5, 9.0, 6.5, 8.0, 5.5,
10.0, 7.0, 8.5, 6.0, 9.5

Resultado apos a ordenacao decrescente:

10.0, 9.5, 9.0, 8.5, 8.0,
7.5, 7.0, 6.5, 6.0, 5.5
